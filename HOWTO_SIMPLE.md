# Pipeline in 4 steps

1. Load your CFB save + Madden save
2. Load CFB Save → Generate Draft Class
3. Export Draft Class File — **name it with letters, numbers and dashes only**
   (no spaces or punctuation, or Madden may bounce you to the main menu on import)
4. In Madden: Franchise → Manage Roster → Import Draft Class

Done — your CFB draft class is now your Madden rookie class.
