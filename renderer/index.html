1 · Player Pool

          
Load the players leaving your CFB dynasty from your college save file.

          

            Best accuracy at Offseason Week 1 (the "Draft Stage").
            That's the one point in a dynasty where the game has finalized exactly
            who's declaring for the draft. Earlier saves work too -- the tool predicts
            who's likely to declare from Junior/Senior rosters -- but the closer you
            are to Week 1, the more accurate the class.

2 · Generate Class

          
Turns your loaded prospects into a full rookie draft class, applying everything you've set on Position Weights, Rating Translation, Rating Categories, and Advanced.

          

            
            

              
              
            

            

          

          

            Recommended: generate once, then move on.
            Each run adds a little randomness on top of your settings (that's
            intentional — real draft classes have that same natural variance), so
            re-running produces a slightly different class every time. Only
            regenerate repeatedly if you're specifically testing how a Position
            Weight or rating change affects the output on the Draft Class page —
            otherwise, generate once and write it into your franchise.
          

          
          

            
            

              Add someone who isn't in your dynasty. They join the pool as an ordinary prospect and
              land wherever their talent puts them — no reserved slot. The overall you enter is a
              college overall and converts down like everyone else's, so enter it
              higher than the Madden rating you're aiming for, then check the Draft Class page and
              adjust. Their build and rating shape are copied from the closest real player at the
              same position.

3 · Export Draft Class File recommended

        
Builds a Madden Import Draft Class file from your generated class — no franchise save needed.
          In Madden: Franchise → Manage Roster → Import Draft Class and pick this file. It replaces the
          whole rookie class (no duplicates), with correct faces, positions, sizes, ratings, archetypes, and dev traits.

        
        
Name it with letters, numbers and dashes only.
          Spaces or punctuation in the file name can make Madden kick you back to the main
          menu when you import. CAREERDRAFT-CFBCLASS2030 works;
          CAREERDRAFT-My Class (v2) may not. The CAREERDRAFT-
          prefix is added for you automatically.

        

          
          

            
          

          

        

        

          A draft-class file has a fixed number of slots — 402 players
          for the game selected above. A class that size or larger fills every slot with your generated players
          (extras are ignored). A smaller class still exports — it fills as many slots as it can and leaves
          the rest as the bundled template's original, unconverted prospects. Go below 224
          (7 full rounds) and even some drafted rounds will include those unconverted fillers, not just the
          undrafted tail. Name the file whatever you like when saving — the app automatically adds the
          CAREERDRAFT- prefix Madden's importer requires, so you don't need to type it yourself.

4 · Write to Madden Franchise alternative

        
Overwrites the incoming rookie class in your Madden 26 franchise save with your generated class,
          writing directly into the save file (no in-game import step). The draft-class file above is usually cleaner.

        

          Your Madden save CANNOT be in Preseason.
          The incoming rookie draft class doesn't exist yet during preseason, so
          there's nothing there for this tool to overwrite. Use a save from Regular
          Season, Postseason, or a later Offseason stage — anything except Preseason.

Position Weights

        

          Roster construction, position by position -- how many of a position
          make the class, and where they land in the draft order. Neither of
          these touches a player's ratings (that's Rating Translation's job).
          Hover any field for details.
        

        

          
        

      

      

        
Class Cap = max players at that position in the class (blank = no limit). Draft Value = draft-ORDER-only bump/penalty for the position (doesn't touch ratings -- just where they land in the class, positive = drafted earlier, negative = later).

        

          
            
PositionClass CapDraft Value (default shown right)

          
          
        

      

    


    
    

      

        
Rating Translation

        

          The heart of the converter: how a college rating becomes a Madden
          rookie rating. Physical traits barely change (a burner stays a
          burner), skills compress moderately, and mental ratings drop the most
          — because rookies rarely process at NFL speed. Every dial here is
          yours. Hover any field for details.
        

        

          
        

      


      

        
Engine

        

      


      

        
Dice Roll

        

          Dice Roll builds every player with the Power Curve settings
          below — so ratings still reflect how the player actually plays — and then
          rolls each player a little luck on top, up or down. Most players barely
          move, a few swing several points, and the class as a whole comes out the
          same strength as a Power Curve class. That's what turns a predictable
          board into one with steals and busts.
        

        

          Everything below this card applies to Dice Roll too. Tune the conversion
          there; tune how much luck here.
        

        

      


      
      

        
UFL Overall Boost

        

          Optional — you don't need this. Tested UFL classes
          already come out averaging in the low 70s overall without it. This
          is only for pushing the class higher still, on top of whatever the
          engine above already produced. Off by default; works the same
          whether you're using Power Curve or Dice Roll, and only ever takes
          effect in UFL mode.
        

        

      


      

        
Overall Class Strength

        

          One dial for the whole class — scales every position's Technical and
          Mental compression at once, on top of whatever you've set below.
          Never touches Physical ratings.
        

        

      


      

        
Category Curves

        

          Each category bends college ratings toward Madden along a curve fixed
          by two calibration points — how much of an elite college
          rating survives, and how much of a good one survives.
          Lower a percentage to make that whole category harsher across the board.
        

        

          
            

              Category
              Elite Rating Keeps
              Good Rating Keeps
            

          
          
        

      


      

        
Per-Position Controls

        

          How hard each position compresses. Technical covers
          route running, coverage, blocking, pass rush, catching, and throw
          accuracy; Mental is Awareness & Play Recognition;
          Physical is athleticism, including Throw/Kick Power --
          all three are proportional (1.0 = the standard amount of drop, lower = stronger,
          higher = weaker; keep Mental ≥ Technical for realistic rookies).
          Extra Drop is different: a flat number of points
          off every rating for that position (all four categories), stacking on top
          of the proportional dials -- useful for nudging an already-compressed
          elite rating, where the proportional dials alone barely move the needle.
        

        

          
            
PositionTechnicalMentalPhysicalExtra Drop (flat)

          
          
        

      


      

        
Global

        

      

    


    
    

      

        
Rating Categories

        

          Every rating belongs to a compression bucket that decides how much of
          it survives the jump to Madden. Editing All positions
          moves a rating's bucket everywhere; switch to a single position below
          to set an exception just for them (e.g. Awareness compresses harder for
          CB specifically, without touching every other position). Extra
          Drop and Max Drop fine-tune one rating further
          — a flat point subtraction and a hard floor — and always stay global no
          matter which position you're viewing.
        

        

          
        

      


      

        These buckets apply to both engines. Dice Roll builds its base
        ratings with Power Curve before rolling each player's luck, so changes here
        affect your class either way.

Advanced

        
Class size, development traits, and draft-order projection weighting. Subtler effects than Position Weights or Rating Translation — each knob explains itself below.

        

          
        

      


      

        
Class Construction

        

      


      

        
Rating Realism on by default

        
Post-translation corrections, on by default. Turn one off if you're already handling the same thing with an external tool, so it isn't applied twice.

        

      


      

        
Development Traits

        
Controls how Normal, Star, Superstar, and X-Factor dev traits get handed out across the class.

        

      


      

        
Board Organization draft order only

        
Picks how the class gets ordered into rounds. CFB Projected Rounds follows the round CFB 27 projected for each player. Realistic Draft Day ignores that entirely, re-ranks the same players on talent, then lets some slide — giving you late-round steals instead of a clean best-to-worst sort. Either way the same players make the class; only where they get drafted changes.

        

      


      

        
Draft Projection draft order only

        
Where a player lands in the class (round/pick) can come from more than just overall -- CFB's own projected round, career awards, elite measurables, and position value all factor in. None of this touches a player's ratings.

Hiring

        
        

          
          
        

      


      

        

          Every placed coach always gets a full talent tree and a face — skipping either
          leaves a coach reading as "Level 1 / DUMMY ARCHETYPE" with no abilities, or as a
          silhouette, in Coach Central. Not exposed here on purpose.
        

      


      

        
Skin Tones

        

          A coach's face carries their skin tone, so the carousel has to pick a
          tone to pick a face. For most coaches CFB states it outright and it's
          matched exactly. But the named, real-life coaches — the ones you're
          most likely to actually move — don't have it stated anywhere, so
          they're the ones the app has to guess at.
        

        

          Set any of them here and that choice is used instead of the guess,
          permanently. Anyone you leave blank keeps guessing — a tone picked to
          match how CFB's coaching pool actually looks overall, and consistent
          run to run rather than random each time.
