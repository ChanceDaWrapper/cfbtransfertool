# How to use Pipeline

1. **Dashboard** — load your **CFB 27 dynasty save** and your **Madden 26 franchise save**. Best on a CFB save at the Offseason Draft Stage (that's when the game has actually finalized who's leaving); a Madden save that's not in preseason.
2. **Open Draft Class → Load CFB Save.**
3. *(Optional)* Tweak ratings/positions/dev traits under the Draft Class settings pages. Defaults work fine if you don't want to touch anything — the big-WR/CB agility fix is already on by default.
4. **Generate Draft Class** → check the results table. Not happy? Adjust and regenerate — nothing's written yet.
5. **Export Draft Class File.** **Keep the file name simple — letters, numbers and
   dashes only.** Madden chokes on spaces and punctuation in a draft-class file
   name: the file still saves, and it may even import from the weekly agenda's
   "select the rookies" screen, but going **Draft Class → Edit → import** can
   kick you straight back to the main menu instead. `CAREERDRAFT-CFBCLASS2030`
   is fine; `CAREERDRAFT-My Class (v2)` is not. The app always adds the
   `CAREERDRAFT-` prefix for you — the rest is up to you.
6. In Madden: **Franchise → Manage Roster → Import Draft Class** → pick that file.

Your CFB draft class is now the Madden rookie class — ratings, dev traits, and combine numbers included.
